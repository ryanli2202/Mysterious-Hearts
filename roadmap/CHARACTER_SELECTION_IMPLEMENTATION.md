## Concrete balance/persistence decisions

The shared MH-001 table is authoritative. Strongest selected combat history or criminal-role experience wins; complete tier profiles are not summed. Career ranks currently add bounded tactical experience of 0.25 / 0.5 / 0.75 / 1 fight-IQ points. These are provisional implementation values, **not** completion of the requested profession-specific power/refinement/conditioning calibration. The dossier labels combat bands as targets. B/low-A unawakened variants explicitly say uncalibrated.

Reputation/heat use the approved catalogue's proposed values: clean 0/0, former 20/0, independent 20/5, freelancer 40/10, trusted crew 30/5, lieutenant 50/10, captain 65/15, faction member 40/5, specialist 50/10, field leader 60/15. A selected crew's advertised entry reputation is a floor. No resources, wages, completed contracts, assignments or friendships are fabricated. Membership uses save-local records, never global canonical role registries.

Civilian ranks initialise the current ladder's craft/reliability plus rank × 4 leadership, with prior experience recorded separately from completed shifts. Career and faction promotion gates include origin experience but still require the next tier's remaining progress; senior career qualification/portfolio gates remain in place. Faction assignment history starts at zero. Selected gang standing uses its existing rank baseline. All of these values require the remaining integrated balance/progression review before MH-002 can be completed.

Drafts live under `character_drafts`, profiles under `custom_characters`, beside `saves`. Drafts use one atomic JSON document with separate manual/current and recovery snapshots, a generation counter and revisions. Limits: 2 MB per draft, 40 unpinned revisions, 80 session undo snapshots. Existing saves are not rewritten by preview. New custom stories carry their own profile and resolved origin snapshots. No restart migration reseeds existing stories.
