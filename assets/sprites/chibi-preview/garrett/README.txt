GARRETT — CHIBI PIXEL ART STYLE PREVIEW

Open idle.gif and walk.gif for looping previews on dark slate at 4x scale.
sprite-sheet.png contains transparent 48x64 cells: 6 columns, idle on row 1,
walk on row 2. Individual PNG frames and timing metadata are included.
source-sheet.png preserves the imagegen output at its original resolution.
contact-sheet.png shows all delivery frames enlarged with nearest-neighbor.

Identity references: assets/portraits/garrett-selection.png,
assets/sprites/side-idle/garrett.png, and the canonical character appearances.
Artwork generated with the built-in image_gen tool. Sharp packages frames,
resizes with nearest-neighbor, and encodes GIFs; it does not draw the poses.
Rebuild using tools/build_garrett_sprite_preview.cjs with the bundled Node.

This is an external style test, not an in-game release of freeroam. Existing
portraits, maps, game UI and saves are unchanged. Final cleanup of generated
frame-to-frame hair/clothing variation, walk gait, and directional coverage
remains before production use. Shoes follow Garrett's existing side illustration.
